# Текущее состояние

**Версия 6.4.0. Последняя проверка 27.11.2026.** Поиск показывает результаты площадок по мере поступления. Добавлены очередь анализа вакансий, отдельный балл по навыкам, обязанности простым языком и настройка порога автооткликов по навыкам.

## Архитектура

- Python 3.12, Telegram long polling, один aiohttp-сервер и SQLite WAL. Mini App использует существующий HTTPS-домен Bothost. Приватные маршруты проверяют подпись данных Telegram, срок и OWNER_ID. Сохраняются предыдущие настройки и записи.
- Вход HH встроен в Mini App, использует существующую короткоживущую ссылку и локальный Chromium. Одно резюме автоматически привязывается, если доступен профессиональный текст. Когда список недоступен, можно открыть свою карточку или вставить ссылку. Фоновый поиск доступен после подтверждения входа. Для писем и откликов действуют прежние условия. Состояние браузера остаётся в `DATA_DIR`. HH API не используется.
- SuperJob подключается по официальному OAuth для соискателей. Приложение хранит токены в SQLite, загружает названия резюме, отправляет выбранное резюме с письмом и отображает результат API. Для подключения нужны ID, ключ и зарегистрированный URL возврата.
- «Работа России» подключена для публичного поиска. Для Хабр Карьеры, Авито Работы, Работа.ру и прочих сайтов можно сохранять карточки по ссылке. Отправка из Mini App доступна через HH и SuperJob. Для отправки нужен постоянный Volume.
- Для автоматической отправки HH после подтверждения владельца нужны выполненные фильтры, общий балл Groq и отдельное совпадение по навыкам от заданных порогов, подтверждённые обязательные требования и письмо из точных выдержек из резюме. Изменённые вручную письма исключены из автовыбора.
- Фоновый HH-поиск хранит в SQLite непрочитанные ID и позицию по запросу, проверяет свежую выдачу и продолжает обход предыдущих страниц. Groq работает в отдельном рабочем цикле, очередь сохраняется между перезапусками. После исчерпания дневного лимита новые обращения возобновляются на следующие сутки. При временных сбоях поиск повторяется, истечение входа или явное ограничение HH останавливают браузерный режим.
- Вакансии могут иметь опубликованную точку офиса. Карта загружает тайлы OpenStreetMap по действию владельца. Для поездок доступны локальный диапазон по прямому расстоянию и необязательные дорожные маршруты HeiGIT. Домашний адрес не сохраняется.
- Подтверждение отправки и неизвестный результат видны в журнале. При неизвестном результате повтор блокируется. Прямой сверкой сейчас располагает HH. Информация о решениях работодателей пока не синхронизируется.

## Проверка

- Локально прошли 116 тестов. Проверены частичная выдача и восстановление после HTTP 504, возобновление фонового поиска, независимая очередь Groq, лимиты и порог автооткликов по навыкам. Мобильный сценарий прошёл в Chromium. Используются синтетические ответы.
- На публичном домене Bothost `/health` и `/mini` ответили HTTP 200. Публичные скрипты совпали с `main` после слияния PR #13. Приватные маршруты ожидаемо вернули 401 без Telegram-подписи. Причина сбоя в сеансе владельца и тариф не подтверждены.
- Реальный вход HH в Telegram на iPhone, токены SuperJob и отправка работодателю из аккаунтов владельца требуют проверки после развёртывания. Тесты используют фиктивные данные и не отправляют заявки на реальные сайты.

## Развёртывание

После слияния PR обновите Git-сборку Bothost, откройте `/app` и проверьте версию в **Аккаунтах**. Убедитесь, что база и сессия HH сохраняются в постоянном `/app/data`. Проверку авторизованного поиска, доступ Groq с ключом владельца и ресурсы тарифа нужно выполнить после выкладки. Реальная тестовая отправка требует отдельного разрешения. [Хранение SQLite на Bothost](https://bothost.ru/docs/sqlite-data-lost)
