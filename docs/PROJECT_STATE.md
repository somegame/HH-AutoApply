# Текущее состояние

**Версия 5.1.0. Последняя проверка 26.11.2026.** Реализован сценарий со штатным автопоиском HH и ручным переносом выбранной вакансии. Версия 5.0.1 запущена на Bothost по скриншоту владельца. Версия 5.0.2 ведёт к штатному автопоиску, автооткликам и истории HH. Загрузка резюме требуется только для ручного анализа. Браузерный режим 5.1 реализован в отдельной ветке. Реальный деплой и работа с аккаунтом владельца предстоят.

## Архитектура и состояние

- Один процесс Python 3.12, Telegram long polling, SQLite WAL в `DATA_DIR`, фоновая очередь, приватный OWNER_ID. В контейнере нет Chromium; Playwright поставляет свой драйвер.
- В ручном режиме вакансии вводятся владельцем. В браузерном режиме поиск читает публичный интерфейс HH. Groq выполняет структурированную оценку, готовит черновик и кэширует результат. При неизвестном исходе оператор проверяет раздел «Отклики» на HH. Отметка в SQLite фиксирует сообщение владельца.
- Browserbase создаёт короткую CDP-сессию, а для входа выдаёт Live View с постоянным контекстом. В образ добавлен клиент Playwright, браузер остаётся на Browserbase. Локально собран образ 5.1 размером около 293 МиБ, импорты внутри контейнера прошли. Реальный CDP Browserbase и авторизация не тестировались.
- Для настроек и истории на Bothost нужен постоянный Volume. Публичные условия указывают Starter 256 МБ RAM/0,5 ГБ SSD, Basic 1 ГБ/5 ГБ, Pro 2 ГБ/15 ГБ. Возможности текущей панели и тарифа владельца пока не проверены. [Bothost](https://bothost.ru/)

## Проверка

- Локально пройдены 23 теста, включая polling через тестовый Bot API, защиту владельца, SQLite и восстановление, дневные ограничения, TXT/DOCX/PDF, кэш, схему Groq, 429 и REST Browserbase через mock. В Chromium проверена тестовая форма с сопроводительным письмом, выбранным резюме, анкетой, CAPTCHA, неизвестным результатом и исчерпанным лимитом. На публичном HH без входа браузер прочитал выдачу и поля вакансии.
- Образ версии 5.0.x собран на Python 3.12 с сертификатом среды, переданным в сборку. Инициализация внутри контейнера измерена примерно в 48 МиБ RSS и 39–40 КиБ для пустой SQLite. Образ около 128 МиБ по Docker image inspect. Локальный rootless Docker не применяет отдельный cgroup-лимит 256 МБ. Пик при работе с документами и использование диска на Bothost не измерялись.
- Доступ к Groq и Browserbase, сохранение Volume между обновлениями и мобильный сценарий HH с аккаунтом владельца предстоит проверить. Настоящие токены и реальные тестовые отклики не использовались.
