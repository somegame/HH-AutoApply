# Текущее состояние

**Версия 5.2.1. Последняя проверка 26.11.2026.** Локальный Chromium заменил внешний сервис. На Bothost достигнут этап запуска 5.2, который прервался из-за формата LOGIN_PUBLIC_URL. В 5.2.1 добавлена поддержка домена из панели. Публичная проверка здоровья домена вернула HTTP 404. Привязка маршрута, вход с iPhone и работа с аккаунтом владельца ожидают проверки.

## Архитектура и состояние

- Python 3.12, Telegram long polling, SQLite WAL, очередь и приватный OWNER_ID.
- Chromium Headless Shell устанавливается при сборке Dockerfile. Для входа с телефона поднимается HTTPS-интерфейс за прокси Bothost, срок ссылки три минуты. Контекст HH сохраняется в `DATA_DIR` с правами 0600.
- Поиск, подготовка писем и отклики используют ту же очередь. Ручной режим по-прежнему доступен.
- Для настроек и истории на Bothost нужен постоянный Volume. Публичные условия указывают Starter 256 МБ RAM/0,5 ГБ SSD, Basic 1 ГБ/5 ГБ, Pro 2 ГБ/15 ГБ. Возможности текущей панели и тарифа владельца пока не проверены. [Bothost](https://bothost.ru/)

## Проверка

- Локально пройдены 32 теста. Проверены защищённые запросы к интерфейсу входа, передача тестового ввода, снимки экрана, закрытие ссылки и сохранение сессии между запусками. Формы отправки проверены на тестовых страницах Chromium. Публичный поиск HH проверялся в версии 5.1.
- Docker-образ с Chromium собран локально. Распакованный размер около 836 МиБ. Реальные лимиты тарифа, авторизация HH с iPhone и фактическая отправка на аккаунте владельца ещё не проверены.
