# Текущее состояние

**Версия 6.0.0. Последняя проверка 26.11.2026.** Версия подготовлена в отдельной ветке, проект работает через одну точку входа `bot.py`. На последнем скриншоте владельца HH уже показал личный профиль, после чего браузерная проверка не подтвердила список резюме. Точная причина сбоя Bothost остаётся неизвестной. Новая версия оставляет окно открытым, если вкладка проверки упала, а основная вкладка HH доступна.

## Архитектура

- Telegram Mini App для iPhone и прежние команды чата используют Python 3.12, long polling, один aiohttp-сервер и SQLite WAL. Сохраняются существующая БД, настройки и журнал. Для Mini App используется HTTPS-адрес Bothost. Приватные маршруты проверяют подпись Telegram, срок её действия и OWNER_ID.
- Встроенная выдача HH использует гостевой контекст локального Chromium без API HH. Браузерная сессия владельца используется для выбора и импорта резюме HH, фоновой обработки и отправки в поддерживаемой форме. При неподтверждённой отправке действует запрет повтора до сверки.
- «Работа России» использует открытый каталог. SuperJob требует ключ приложения для поиска. Для Хабр Карьеры, Авито Работы, Работа.ру и других сайтов доступны ссылки на поиск или добавление карточки вручную. Отклики на этих сайтах отправляются самостоятельно и отмечаются в общей истории.
- Ссылки входа HH живут восемь минут. Состояние сессии хранится в `DATA_DIR` с правами 0600. Отправка из браузера требует постоянного Volume. Публичные условия Bothost указывают Starter 256 МБ RAM/0,5 ГБ SSD, Basic 1 ГБ/5 ГБ, Pro 2 ГБ/15 ГБ. Фактические квоты владельца требуется подтвердить в панели. [Bothost](https://bothost.ru/)

## Проверка

- Локально пройдены 38 тестов, включая мобильный сценарий Mini App в Chromium, проверку подписи Telegram, временный сбой проверки входа HH, изоляцию ошибок поисковых источников и переходы статусов в SQLite.
- По запросу «Финансовый менеджер», Москва, от 150 000 ₽, публичные проверки вернули 11 вакансий из каталога «Работа России» и 3 вакансии с сайта HH. Тестирование доставки в Telegram, авторизации HH, Groq и откликов в аккаунте владельца на Bothost остаётся отдельным шагом. Для живой проверки SuperJob нужен ключ.
- Предыдущий локальный Docker-образ с Chromium занимал около 836 МиБ в распакованном виде. Потребление RAM текущей версии на выбранном тарифе ещё не измерено.

## Развёртывание и проверка с телефона

После слияния PR обновите Git-сборку в Bothost, откройте `/app` в личном чате и проверьте поиск, затем вход на HH и импорт резюме. Проверьте доступ к постоянному Volume после повторного деплоя. Реальная тестовая отправка требует отдельного разрешения.
