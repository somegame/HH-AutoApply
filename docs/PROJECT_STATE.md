# Текущее состояние

**Версия 6.1.0. Последняя проверка 26.11.2026.** На скриншоте владельца версия 6.0 показывала редактируемое резюме HH, но подтверждение зависело от доступности списка резюме. В 6.1 личная страница резюме с видимой кнопкой редактирования служит отдельным подтверждением владения.

## Архитектура

- Python 3.12, Telegram long polling, один aiohttp-сервер и SQLite WAL. Mini App использует существующий HTTPS-домен Bothost. Приватные маршруты проверяют подпись данных Telegram, срок и OWNER_ID. Сохраняются предыдущие настройки и записи.
- Вход HH встроен в Mini App, использует существующую короткоживущую ссылку и локальный Chromium. Если HH показывает одно принадлежащее владельцу резюме и доступен профессиональный текст, он привязывается к профилю. При нескольких резюме есть выбор. Состояние браузера остаётся в `DATA_DIR`. HH API не используется.
- SuperJob подключается по официальному OAuth для соискателей. Приложение хранит токены в SQLite, загружает названия резюме, отправляет выбранное резюме с письмом и отображает результат API. Для подключения нужны ID, ключ и зарегистрированный URL возврата.
- «Работа России» подключена для публичного поиска. Для Хабр Карьеры, Авито Работы, Работа.ру и прочих сайтов можно сохранять карточки по ссылке. Отправка из Mini App доступна через HH и SuperJob. Для отправки нужен постоянный Volume.
- Подтверждение отправки и неизвестный результат видны в журнале. При неизвестном результате повтор блокируется. Прямой сверкой сейчас располагает HH. Информация о решениях работодателей пока не синхронизируется.

## Проверка

- Локально пройден 41 тест. Среди проверок мобильная ширина 320 и 390 пикселей, изоляция источников, привязка редактируемого резюме без личного списка HH, отказ на публичной карточке, одноразовый OAuth state, выбор резюме SuperJob, успешный и неизвестный результат отправки с фиктивным API.
- Интерфейс проверен по мобильным снимкам в Chromium и рекомендациям Telegram и Vercel. Применён публичный скилл Frontend Design от Anthropic. [Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) · [Web Interface Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)
- Реальный вход HH в Telegram на iPhone, токены SuperJob и отправка работодателю из аккаунтов владельца требуют проверки после развёртывания. Тесты используют фиктивные данные и не отправляют заявки на реальные сайты.

## Развёртывание

После слияния PR обновите Git-сборку Bothost, откройте `/app` и проверьте вход HH из вкладки **Аккаунты**. Для SuperJob настройте `SUPERJOB_CLIENT_ID`, `SUPERJOB_API_KEY` и URL возврата `<LOGIN_PUBLIC_URL>/mini/oauth/superjob`. Реальная тестовая отправка требует отдельного разрешения.
