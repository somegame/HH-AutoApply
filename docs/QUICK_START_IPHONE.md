# Быстрый запуск с iPhone

1. Откройте [Bothost](https://bothost.ru/create-bot.php). Подключите `somegame/HH-AutoApply`, ветку `main` после публикации и слияния изменений. При наличии режима Dockerfile выберите его. Для сборки Python главный файл — `bot.py`.
2. Добавьте `TELEGRAM_TOKEN`, `OWNER_ID` и `GROQ_API_KEY`. Если тариф даёт постоянный Volume, подключите его и укажите `DATA_DIR=/app/data`, `PERSISTENT_STORAGE=true`. Запустите одну реплику. При отсутствии Volume данные могут исчезнуть при обновлении.
3. Откройте личный чат с ботом, отправьте `/start`. Нажмите **Моё резюме** → **Загрузить / заменить** и пришлите резюме без контактов. Проверьте текст и разрешите анализ в Groq.
4. Нажмите **Авторизация HH**. Войдите в HH через Safari или приложение, затем откройте **Мои резюме на HH** и проверьте, что видите свой аккаунт. Код входа вводится на HH.
5. Нажмите **Запустить поиск**. Откройте подходящий запрос, уточните фильтры и включите штатный автопоиск HH. [Настройка автопоиска с телефона](https://feedback.hh.ru/knowledge-base/article/0048)
6. Отправьте боту ссылку интересующей вакансии и заполните предложенную карточку. В очереди проверьте анализ, при необходимости отредактируйте письмо, затем подтвердите черновик.
7. Нажмите **Открыть на HH.ru**, сверьте прежние отклики и выберите резюме HH. Отправьте письмо и проверьте запись в разделе «Отклики». Затем нажмите **Отметить отправку** в карточке бота.

Если шаг 2 недоступен на вашем тарифе, проверьте в панели доступ к пользовательским переменным и постоянному хранилищу. Ключи в GitHub не добавляйте. Команда `/diagnose` помогает проверить подключение после запуска.
