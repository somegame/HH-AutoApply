# Быстрый запуск с iPhone

1. Откройте [Bothost](https://bothost.ru/create-bot.php). Подключите `somegame/HH-AutoApply`, ветку `main` с актуальной версией проекта. В дополнительных настройках включите **Использовать собственный Dockerfile**. Это особенно важно, если автоматическая сборка завершилась ошибкой `import telegram`.
2. Добавьте `TELEGRAM_TOKEN`, `OWNER_ID` и `GROQ_API_KEY`. Если тариф даёт постоянный Volume, подключите его и укажите `DATA_DIR=/app/data`, `PERSISTENT_STORAGE=true`. Запустите одну реплику. При отсутствии Volume данные могут исчезнуть при обновлении.
3. Откройте личный чат с ботом и отправьте `/start`. Нажмите **🔑 Проверить вход** → **Мои резюме на HH**. Если открылись ваши резюме или страница управления ими, сессия HH работает в этом браузере. Вернитесь в Telegram и нажмите **➡️ Продолжить**.
4. Нажмите **🔎 Подобрать вакансии**, откройте запрос и сохраните его на HH. Новые вакансии приходят через уведомления HH. [Автопоиск с iPhone](https://feedback.hh.ru/knowledge-base/article/0048)
5. Для автоматических откликов нажмите **⚡ Автоотклики HH**. На главной HH проверьте **Автоматические отклики → Настройки** и используемое резюме. Если нужен HH Pro, проверьте условия доступа до подтверждения. Отправленные с сайта заявки видны через **📨 Отклики HH**. [Условия HH Pro](https://hh.ru/article/hhpro_offer)
6. **✍️ Анализ вручную** нужен только для отдельного письма в Telegram. Если захотите этот режим, подготовьте текст резюме без контактов, разрешите Groq и добавьте выбранную вакансию.

Если шаг 2 недоступен на вашем тарифе, проверьте в панели доступ к пользовательским переменным и постоянному хранилищу. Ключи в GitHub не добавляйте. Команда `/diagnose` помогает проверить подключение после запуска.
